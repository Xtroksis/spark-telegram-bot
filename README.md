# Spark — демо Telegram-бот

Демо-бот на Python (pyTelegramBotAPI), показывающий основные возможности Telegram-ботов:

- меню с inline-кнопками
- хранение данных в JSON (искры, уровни, бонус дня)
- приём заявок с пересылкой владельцу
- мини-игры и случайные подборки

## Запуск

1. `pip install pyTelegramBotAPI`
2. Скопируй `config.example.py` в `config.py` и вставь токен от @BotFather
3. `python bot.py`
